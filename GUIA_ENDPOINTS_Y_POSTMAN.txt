 GUÍA COMPLETA DE PETICIONES POSTMAN - PROYECTO NEXUS GAMES (API REST + SQL + JWT)
===================================================================================

Este archivo contiene la guía paso a paso para configurar y probar todas las peticiones 
en Postman, organizadas por método HTTP (GET, POST, PUT, PATCH, DELETE), incluyendo 
ejemplos exactos de URLs, Headers, Cuerpos JSON (Body) y Respuestas esperadas.

-----------------------------------------------------------------------------------
 📌 1. PASOS GENERALES PARA USAR POSTMAN CORRECTAMENTE
-----------------------------------------------------------------------------------

PASO 1: Asegúrate de tener el Backend encendido
   En la terminal del backend:
   > npm run dev
   (El servidor debe indicar: 🚀 SERVIDOR BACKEND ACTIVO EN: http://localhost:5000)

PASO 2: Configurar una Petición POST, PUT o PATCH con Body JSON
   1. Abre Postman y crea una nueva pestaña con el botón [+].
   2. Selecciona el Método correspondiente (POST, PUT o PATCH).
   3. Escribe la URL (Ejemplo: http://localhost:5000/api/auth/login).
   4. Ve a la pestaña "Body" (debajo de la barra de URL).
   5. Selecciona el botón radial "raw".
   6. En el menú desplegable a la derecha (donde dice "Text"), cámbialo a "JSON".
   7. Pega tu JSON en el editor y haz clic en el botón azul "Send".

PASO 3: Cómo usar el Token JWT en Peticiones Protegidas (GET, POST, PUT, PATCH, DELETE)
   Cuando hagas Login o Registro, el servidor te devolverá un "token" largo.
   Para usarlo en los endpoints que requieren autenticación:
   - Opción A (Recomendada): 
     En Postman, ve a la pestaña "Authorization" -> Tipo: "Bearer Token" -> Pega el token.
   - Opción B (Manual por Headers):
     Ve a la pestaña "Headers" -> Agrega una fila:
     Key: Authorization
     Value: Bearer <PEGA_TU_TOKEN_AQUÍ>

PASO 4: Importar la Colección Automática (Opcional)
   En Postman, presiona el botón "Import" y selecciona el archivo:
   d:\Entregable3\backend\postman\Nexus_Games_API.postman_collection.json

 🔐 2. MÓDULO DE AUTENTICACIÓN (AUTH & TOKEN JWT)
===================================================================================

-----------------------------------------------------------------------------------
[POST] 2.1 INICIAR SESIÓN (GENERACIÓN DE TOKEN JWT)
-----------------------------------------------------------------------------------
Descripción: Valida usuario y contraseña cifrada con Bcrypt y genera el Token JWT.
Método: POST
URL: http://localhost:5000/api/auth/login
Headers:
  Content-Type: application/json

Body (raw -> JSON):
{
  "email": "admin@nexusgames.com",
  "password": "Admin123*"
}

Cuentas de Prueba Pre-registradas:
- Admin: email: "admin@nexusgames.com" | password: "Admin123*"
- Empleado: email: "empleado@nexusgames.com" | password: "Empleado123*"
- Cliente: email: "cliente@nexusgames.com" | password: "Cliente123*"

Respuesta Exitosa (200 OK):
{
  "success": true,
  "message": "¡Bienvenido de nuevo, Administrador!",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "nombre": "Administrador",
    "apellido": "Nexus",
    "email": "admin@nexusgames.com",
    "rol_id": 1,
    "rol_nombre": "Administrador",
    "estado": "Activo"
  }
}

[POST] 2.2 REGISTRO DE NUEVO CLIENTE (GENERA TOKEN JWT)
-----------------------------------------------------------------------------------
Descripción: Registra un nuevo usuario en la base de datos SQL con validaciones:
- Teléfono: exactamente 10 dígitos numéricos.
- Contraseña: mínimo 8 caracteres con al menos un símbolo especial (!@#$%&*...).
- Nombres: entre 2 y 40 letras.
- Documento: entre 6 y 12 caracteres.
Método: POST
URL: http://localhost:5000/api/auth/register
Headers:
  Content-Type: application/json

Body (raw -> JSON):
{
  "nombre": "Sebastian",
  "apellido": "Vargas",
  "tipo_documento": "CC",
  "numero_documento": "1040506070",
  "direccion": "Calle 45 # 12-34, Medellín",
  "telefono": "3129876543",
  "email": "sebastian.vargas@ejemplo.com",
  "password": "GamerPassword2026*"
}

Respuesta Exitosa (201 Created):
{
  "success": true,
  "message": "¡Usuario registrado exitosamente!",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 4,
    "nombre": "Sebastian",
    "apellido": "Vargas",
    "email": "sebastian.vargas@ejemplo.com",
    "rol_id": 3,
    "rol_nombre": "Cliente",
    "estado": "Activo"
  }
}
